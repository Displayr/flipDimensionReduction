# Agent rules

This repository is public. Anyone can read everything in it: the code,
commit messages, pull request descriptions, review comments, and the
edit history of each.

- Write pull requests, commit messages, code comments and review
  replies so they read well to someone outside Displayr: describe the
  technical change and nothing more.
- Leave out private information, internal processes and internal links.
- Never identify a customer: no names, company names, email addresses,
  account or document IDs, or anything copied from their data. Say
  "a customer" instead.
- Use made-up test data. To reproduce a customer's bug, copy the shape
  of their data with made-up names and values.
- Read everything through before each push or post.
